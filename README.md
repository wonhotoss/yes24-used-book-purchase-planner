# used-book-crawler — yes24 중고책 구매처 계획

사고 싶은 중고책 목록을 주면, yes24 중고샵에 올라온 판매 건을 전부 모은다. 그다음 **책값 + 판매자별 배송비** 총액이 가장 작아지도록 책마다 어느 판매자에게 살지 정한다.

2026-10-05 착수. 원안은 [ideation.txt](ideation.txt). 이 문서는 원안 검토 결과와 첫 프로토타입을 정리한다.

## 검토 결론

| 질문 | 결론 |
|---|---|
| Open API(developers.yes24.com)가 도움이 되나 | **중고 데이터는 없다.** 제공 범위는 Category API 9개(베스트셀러·신상품 등)와 Goods API 4개(검색·상세·작가·목차)뿐이고, 응답에는 새책 정가·판매가만 있다. 판매자·중고가·배송비는 없다. 키 발급에는 yes24 로그인이 필요하다. 쓸모가 있다면 판본 식별(ISBN ↔ itemId) 정도다. 그런데 중고샵 검색이 ISBN을 그대로 받으므로 **지금은 쓰지 않는다.** 중고 허브 번호가 곧 새책 상품번호(= API `itemId`)라서 나중에 붙이기는 쉽다 |
| 브라우저 도구가 필요한가 | **수집에는 필요 없다.** 중고 판매 목록은 로그인·JS 없이 정적 HTML로 내려온다(아래 "수집 경로"). 브라우저는 마지막 단계, 즉 **계획대로 카트에 담아 실제 결제 금액을 대조할 때만** 쓴다. 그 단계에는 사용자 로그인이 필요하다 |
| 배송비 묶음이 실제로 의미가 있나 | **있다.** 시험용 8권에서 판매 건 533개, 판매자 144곳이 나왔다. 그중 63곳이 2권 이상, 27곳이 4권 이상을 갖고 있었고, 한 곳(`stystem1`)은 8권을 다 갖고 있었다 |
| 어떻게 푸나 | 무료배송 기준액 때문에 "조금 비싼 책을 같은 판매자에게서 사서 무료배송을 넘기는" 해가 나온다. 그래서 탐욕법은 안 되고 **정수계획(MILP)** 으로 푼다. 수십 권은 CBC가 즉시 푼다. 무작위 소규모 문제 40개로 전수탐색과 대조했고 모두 일치했다 |
| 수집 허용 범위 | `robots.txt`가 `/Product/UsedShopHub/Hub`와 `/24/UsedShop/`을 막고 있다. 그래서 **개인용·요청 시 1회·저속**으로만 돌린다. 요청 간격은 1초 이상이고, 결과는 재배포하지 않는다. 목록 하나(10권 안팎)에 약 30~50회 요청한다. 상시 크롤링이나 가격 감시처럼 규모가 커지면 다시 검토한다 |

## 수집 경로

로그인 없이 GET 두 종류만 쓴다.

1. **검색** `GET /product/search?domain=USED_GOODS&query=<제목|ISBN>` → 책(판본)마다 `a.gd_name[href*=UsedShopHub/Hub/{goodsNo}]`와 채널별 건수가 나온다
2. **판매 목록** `GET /Product/UsedShopHub/GoodsList?goodsNo=N&masterGoodsNo=N&delvType=&pageNumber=P&sortGb=01&levelGb=00&saleTypeGb=00` → 허브 페이지가 AJAX로 불러오는 목록 조각이다(`usedShopHub.js`). 한 페이지에 24건이 들어 있다. 판매 건마다 `li[salePrice][levelGb][data-goods-no]`가 하나씩 있다

판매 건에서 읽는 것은 가격, 등급(최상·상·중·하), 채널, 판매자(`/mall/{id}/` → 배송비 묶음 단위), 배송비 문구, 만족도, 사업자 여부다.

### 채널과 배송비 규칙

| 채널 (`delvType`) | 판매자 단위 | 배송비 | 출처 |
|---|---|---|---|
| 예스24배송 (`C2B`) | yes24 하나 | 2,500원, 15,000원 이상 무료 | [배송비 안내 팝업](https://m.yes24.com/Goods/Popup?viewName=DeliveryFee_Popup) — 목록에는 "유료"로만 표기 |
| 매장ON (`OFFSTORE`) | **지점마다 별도**(목동점·청주NC점…) | 2,500원, 20,000원 이상 무료(관찰값, 지점별 문구를 그대로 읽음) | 목록 문구 |
| 판매자 배송 (`C2C`) | 판매자마다 | 판매자마다 다름 | 목록 문구 |

배송비 문구는 시험용 8권에서 네 가지 형태만 나왔다. 모르는 형태가 나오면 `ValueError`로 멈춘다.

| 형태 | 건수 | 해석 |
|---|---:|---|
| `배송비 : N원, S에서 직접 배송` | 400 | 늘 N원(무료 기준 없음) |
| `배송비 : N원, S에서 M원 이상 구매 시 무료배송` | 126 | 판매자 합계 M원 이상이면 0 |
| `배송비 : 무료` / `무료배송, S에서 무료배송` | 6 | 0 |
| `배송비 : 유료 (예스24배송 중고도서 15,000원 이상 무료)` | — | 예스24배송 상수 |

## 사용법

```
pip install -r requirements.txt
python -m ubc examples/sample.txt -o plan.md            # 계획 + 판매 건 스냅숏(plan.offers.json)
python -m ubc list.txt --min-grade 상 --min-rating 4     # 등급 '상' 이상, 판매자 만족도 4점 이상
python -m ubc list.txt --exclude stystem1 --cache .cache  # 판매자 제외, HTML 캐시(같은 날 재실행용)
python -m pytest tests
```

목록 파일은 한 줄에 책 한 권이다.

```
클린 코드 인사이트          # 검색어 — 중고샵 검색 1순위 판본
9788966260959              # ISBN도 됨
데미안 = 176787 8156036     # 판본 고정 — 이 상품번호들 중 아무거나
```

검색어로 준 책은 1순위 판본을 쓴다. 보고서의 "책 정보"에 고른 판본과 다른 판본 후보(상품번호)가 나온다. 판본이 틀렸으면 `= 번호`로 고정하면 된다.

## 시험 결과 — [examples/sample-plan.md](examples/sample-plan.md)

개발서 4권 + 교양서 4권(데미안은 민음사·문학동네 판본 중 아무거나):

- 최적 계획: **96,000원**(책 79,900 + 배송 16,100, 주문처 4곳)
- 비교 기준(책마다 배송비 포함 최저가를 따로 사기): 101,790원(주문처 8곳)
- **5,790원(5.7%) 절약.** 한 판매자에게 4권을 몰았다. 그 판매자의 총균쇠는 최저가보다 비싸지만, 배송비 한 번으로 넷을 받는 쪽이 싸다

판매 건 스냅숏은 `examples/sample-plan.offers.json`에 있다(2026-10-05 시점).

## 구조

```
ubc/yes24.py      수집: 검색 → 후보 판본, 허브 → 판매 건(전 페이지), 배송비 문구 해석
ubc/optimize.py   MILP(PuLP + CBC): 책마다 판매 건 1개, 판매자 이용·배송비 면제 이진변수
ubc/__main__.py   CLI: 목록 읽기 → 판본 해석 → 수집 → 최적화 → 마크다운 보고서
tests/            파서(2026-10-05 저장 HTML fixture), 최적화(전수탐색 대조)
examples/         시험용 목록과 결과
```

## 미확인·다음

1. **카트 대조(가장 큰 가정).** "직접 배송" 판매자에게서 여러 권을 사도 배송비가 **한 번만** 붙는다고 가정했다. 판매 건 400개가 이 형태라서, 가정이 틀리면 계획 전체가 틀린다. 계획 하나를 실제 카트에 담아 결제 직전 금액과 대조한다. 로그인이 필요하므로 사용자가 직접 하거나 Playwright로 한다
2. 예스24배송 중고가 **새책과 합산되어** 15,000원 기준을 넘는지 확인한다(새책을 같이 사는 경우)
3. 판본 해석: 1순위 자동 선택이 틀리는 경우가 있다(코스모스 2006판 vs 2004판). 후보를 보여 주고 고르게 하거나, "아무 판본이나" 옵션으로 같은 제목·저자의 판본을 묶는다
4. 필터 추가: 소장용/일반(`saleTypeGb`), 사업자만, 수량 2권 이상
5. 출력: HTML 보고서, 판매 건 링크에서 카트로 바로 담기
